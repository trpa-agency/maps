Design System

The colors, type, components, and page patterns behind TRPA's web tools, documented from the tools that ship on maps.trpa.gov. Built on Esri's Calcite Design System, with TRPA's brand layered on top and two sub-brands for program work.

01Overview

One system, three brands. Every TRPA browser tool is a single HTML file built on the same four libraries, styled by one token file, and wrapped in one of three brand layers chosen by the program it serves.

How the layers fit

LayerWhat it isWhere it lives
CalciteEsri's design system supplies the components: buttons, selects, switches, dialogs, tabs, notices, loaders, icons. We do not restyle them beyond brand tokens.js.arcgis.com/calcite-components/5.0
TokensRaw palettes, semantic brand tokens, status colors, chart colorways, shape and shadow, and the Calcite variable mapping. Three brand layers scoped by data-brand.assets/trpa-tokens.css
ShellHeader, side panel, map, drawer, footer. The structural chrome is always agency blue even when the content inside carries a sub-brand.This page, section App shell

Required stack

  • Calcite Design System 5.0 for UI components and icons.
  • ArcGIS Maps SDK for JavaScript 4.31 for maps and spatial queries.
  • Plotly.js 2.35 for every chart.
  • AG Grid Community 33 for every data table.

Loaded from CDN in that order of concern, with the UMD libraries (Plotly, AG Grid, jsPDF) placed before the ArcGIS SDK script so Dojo does not swallow them. No build tools, no frameworks, no Bootstrap or Tailwind beside Calcite.

Documentation here describes what the shipped tools do today. When a tool and this page disagree, fix one of them; the page is not aspirational.

Mixing brands

Do
  • Keep the header, back link, and footer in the agency shell on every tool, with the program logo added beside the TRPA logo for EIP tools.
  • Switch the sub-brand on the content area only, with one attribute.
  • Use the sub-brand's chart colorway inside its content.
Don't
  • Recolor Calcite buttons to a category color. Buttons are always the brand primary.
  • Invent a palette for a new program. Use the agency palette until a program has its own brand guide.
  • Put Tahoe Living's warm cream behind an agency tool.

03Color

Hex values are the agency's Pantone conversions. Click any swatch to copy its hex. The badge on each swatch is the contrast ratio against white: AA text passes 4.5 to 1 for body text, AA large passes 3 to 1 for icons, large type, and borders, and fill only means use it as a fill with dark text on top.

TRPA agency palette

Primary

Agency earth palette

Orange, earth, olive, and ice fail contrast as text on white. Use them as fills, borders, and chart marks. When orange must carry text, such as a Beta chip, use the text step --brand-accent-text (#B55A10) instead.

Neutrals

Grays are tinted toward navy, never pure. The light background is the page color; white is the surface color for panels, cards, and controls.

Status

Status colors come from the agency palette so an alert never looks imported. Each has a light tint for backgrounds and, where the base fails as text, a darker text step.

Complete, passing, on track Needs attention, beta, pending Error, excluded, declining Informational, selected

EIP palette

Four Pantone colors from the EIP brand guide. EIP Blue measures 4.45 to 1 on white, just under AA for text, so text-sized blue uses --eip-blue-text (#0068A8); fills keep EIP Blue. The same rule gives orange its text step.

Tahoe Living palette

Earth tones with warm neutrals. The page background is cream, not gray, and borders are sand-tinted. Only sage, forest, and pine pass as text on white.

Chart colorways

Categorical series cycle through the brand colorway in order. Keep to four series where possible; past four, consider a different chart. The preview brand switch repaints the chart in the Charts section.

Map symbology

  • Selection is brand primary at 28 percent fill with a 2px outline.
  • Subject or focus feature is accent orange at 50 percent fill with a 3px outline.
  • Buffers and study areas are a dashed accent outline with no fill.
  • Basemap is gray-vector so data colors read over it.

Type scale for tools

Tools run at a 14px base because they are dense, map-first workspaces. Documentation and gallery pages run at 15px. Hierarchy comes from weight, case, and letter spacing rather than from large size jumps.

Rules

  • Body text is brand dark (navy), never pure black.
  • Help text and labels are --gray-text (#6B7688). Lighter grays are decoration only.
  • Uppercase is reserved for small labels: overlines, section titles, badges, column headers. Never uppercase a sentence.
  • Sentence case for buttons, headings, and labels. Title Case only for proper names like Regional Plan.
  • Numbers in data use tabular alignment where columns compare values; thousands get a comma, no needless decimals.

16App shell

Every map tool shares one shell: a thin white header, a side panel of numbered steps with pinned actions, the map, and a results drawer that slides up under the map. On phones the panel stacks below the map. The shell is always agency; only the content inside takes a sub-brand.

  1. Header. White, 1px bottom border. Logo at 36px, agency overline in brand blue, tool name, a back link to "All maps and apps". Right side: Beta chip, about button, external links.
  2. Search. First thing in the panel. Address, APN, or project with grouped suggestions.
  3. Numbered sections. Each step of the workflow: title, one line of help, controls. Collapsible when long.
  4. Pinned footer. Status line plus the primary action and full-width exports. Never scrolls away.
  5. Map. Gray vector basemap, selection in blue, subject in orange, dashed buffer. Legend card top right, Home and tool buttons on the right edge.
  6. Drawer. AG Grid results under the map, with a count, quick filter, CSV, and a collapse control. 42 percent of height by default.
  7. Map tools. Esri-style square buttons; an active tool fills brand primary, an active refine tool fills accent.

18Map conventions

  • Basemap gray-vector. Imagery only on explicit toggle.
  • Initial view centered on the lake, [-120.04, 39.09], zoom 10, unless the tool opens on a feature.
  • Widgets Home always. Legend when more than one symbol is on the map. Attribution stays on. No Zoom widget on phones.
  • Selection brand primary, 28 percent fill, 2px outline. Subject accent, 50 percent fill, 3px outline. Buffers dashed accent, no fill.
  • Popups use the brand font, 380px wide, with the same tiles, badges, and key-value blocks as the panel.
  • Highlight on hover from the grid: the matching feature flashes in accent.
  • Exports add the TRPA logo bottom right, a scale bar, and a one-line source credit.
  • Services come from maps.trpa.org/server/rest/services. On the office network, fetches fail on CORS; use JSONP with callback= as the fallback.

19States

A panel is empty, loading, showing results, or failing. Design all four.

No parcel selected. Search an address or APN above, or click a parcel on the map. You can add more than one.
Loading 2012 to 2026 history for 025-451-12
The parcel service did not respond. Nothing changed. Try again in a minute, or click the map instead of searching.
No parcels inside 300 feet. Widen the distance, or check that the subject parcel is right.
  • Empty states explain the first action in one sentence and the second in another.
  • Loading states say what is loading and, when it is long, how far along.
  • Errors say what failed, what was saved, and what to try. No stack traces, no codes.
  • Disabled buttons carry a title explaining what enables them.

20Accessibility

  • Contrast. Text meets WCAG 2.2 AA at 4.5 to 1. Help text is #6B7688, not lighter. EIP Blue and all oranges get their text steps when they carry words.
  • Focus. :focus-visible draws a 2px brand outline with 2px offset on everything, including custom buttons.
  • Targets. Minimum 28px tall for in-panel controls, 44px for anything a phone thumb hits.
  • Labels. Icon-only buttons set label or aria-label. Fields wrap their control in a label.
  • Hover is not the only state. :active mirrors :hover so touch gets feedback.
  • Color is not the only signal. Status badges carry words. Chart series have a legend. Excluded rows are struck through as well as grayed.
  • Motion. Transitions stay under 150ms. Nothing animates on load.
  • Viewport. 100dvh with a 100vh fallback so phone browser chrome does not hide the footer.
