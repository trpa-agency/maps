A shared workbench for the Environmental Improvement Program's annual priority lists. It reads the project records the EIP Project Tracker publishes, collects each working group's priorities, combines them, and exports them in the layout of the master priority sheet. There is no automatic scoring: every priority on the list was set by a reviewer.

  1. Two lists. The LTRA list is the annual Lake Tahoe Restoration Act request. The Other list holds priorities for every other funding source. Both draw from one pool, EIP projects in planning or implementation, and the reviewer decides which list a project goes on.
  2. Picks. For each project a reviewer sets a priority (1, 2, or 3, the same tiers as the master sheet), a funding request in dollars, the LTRA criteria the project meets, and a note. Send my picks sends both lists to the survey's layer after a confirmation. Submissions land in TRPA's ArcGIS Online; the tool reads everyone's latest picks back (without email addresses).
  3. How picks combine. For each project the tool counts how many reviewers called it Priority 1, Priority 2, and Priority 3. The ranking is by Priority 1 votes, then Priority 2, then Priority 3, then name. Group priority is the tier most reviewers gave; Request is the median of their requests. Projects nobody picked have no rank. The convener's working group leads settle the final tier and dollar figure from this picture.
  4. Candidate pool. Filter by focus area, implementer, stage, funding status, Tracker LTRA history, program, tag, funding source, and state.
  5. Available funding. Enter a dollar amount for the current list. Picked projects are funded in rank order by their request (or unfunded need where none was given). Pinned projects go first; excluded projects leave the pool.
  6. Master sheet CSV. The combined LTRA list grouped by working group with Priority 1 and all-priority totals, in the column order of the master sheet. Federal Agency and Project Type are not in the Tracker and are left for the leads to fill in.

Data

  • EIP Project Tracker (Lake Tahoe Info), via the nightly snapshot in trpa-agency/EIP.

Caveats

  • Only projects in the Tracker can be picked. A project that is not there yet needs to be entered by its implementer first; the process asks for that anyway, since the Tracker's secured and requested funding should match the list.
  • Tracker LTRA shows what the project's expected funding table on the Tracker says about Lake Tahoe Restoration Act money: requested but not secured, and secured before. It is a hint for building the list and a check for drift between the Tracker and the request entered here. The two are not reconciled automatically.
  • Unfunded need, secured funding, and cost are self-reported by implementers and only as current as their last Tracker update.
  • Your own picks count toward the group once they are sent. Picks and notes are also kept in this browser until you clear them.
  • The table opens in a reviewer view. All columns above the table shows costs and Tracker details.
  • This tool does not write to the Tracker. Submitted picks live in TRPA's ArcGIS Online; the exports carry the lists forward.
